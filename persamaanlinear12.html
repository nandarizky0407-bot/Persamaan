Rekap

Kesimpulan Hari Ini

  1. Persamaan linear: kesetaraan dengan variabel berpangkat satu — grafiknya garis lurus.
  2. PLSV (ax + b = c) tepat satu solusi: seimbangkan kedua ruas sampai x sendirian.
  3. Soal cerita diterjemahkan lewat kata kunci: “total”, “sisa”, “kali”, “lebih”.
  4. PLDV (ax + by = c) solusinya pasangan (x, y) — tak terhingga banyaknya, terhampar di sepanjang garis.
  5. SPLDV meminta pasangan yang memenuhi dua persamaan sekaligus: grafiknya titik potong dua garis.
  6. Tiga senjata SPLDV: substitusi, eliminasi, dan campuran — pilih yang tercepat!
Kartu contekan PLSV : ax + b = c → x = (c − b) / a
PLDV : ax + by = c → pasangan (x, y)
SPLDV : 2 persamaan → titik potong
SUBSTITUSI : ubah → masukkan → selesaikan
ELIMINASI : samakan koefisien → jumlah/kurang
CAMPURAN : eliminasi dulu, substitusi sisanya

Bab Berikutnya

What's Next — SPLTV

Lain hari kita bertemu Sistem Persamaan Linear Tiga Variabel (SPLTV): tiga persamaan, tiga variabel.

a₁x + b₁y + c₁z = d₁

Grafiknya bukan lagi garis, melainkan bidang datar di ruang 3D — solusinya tempat tiga bidang bertemu di satu titik.

Strateginya persis seperti hari ini: eliminasi bertahap — hilangkan satu variabel dari dua pasang persamaan sehingga SPLTV “menyusut” menjadi SPLDV, lalu selesaikan seperti biasa.

Contoh: x + y + z = 6 ; 2x − y + z = 3 ; x + 2y − z = 2 → solusinya (1, 2, 3). Coba periksa sendiri!
